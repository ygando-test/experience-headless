## How to Publish (5 Minutes)

### Step 1: Open the File (30 seconds)
1. Open **`playbook-embed.html`** in any text editor
   - Mac: TextEdit, VS Code, or Sublime Text
   - Windows: Notepad, Notepad++, or VS Code
2. Select all (Cmd+A / Ctrl+A)
3. Copy (Cmd+C / Ctrl+C)

### Step 2: Create Page in Google Sites (1 minute)
1. Go to your Google Site
2. Click **Pages** (left sidebar)
3. Click **+ New Page**
4. Name: **"Headless Experience Design Playbook"**
5. Page type: Choose **Full page** (important!)
6. Click **Create**

### Step 3: Embed the Playbook (2 minutes)
1. On the new page, click **Insert** → **Embed**
2. Click **Embed code** tab
3. Paste the code you copied (Cmd+V / Ctrl+V)
4. Click **Next**
5. Click **Insert**

### Step 4: Adjust Settings (1 minute)
1. Click the **Settings** gear icon (⚙️) for the page
2. Set these options:
   - ✅ **Show page in navigation:** ON
   - ✅ **Page width:** Full width
   - ❌ **Show page title:** OFF (embed has its own title)
3. Click **Done**

### Step 5: Publish (30 seconds)
1. Click **Publish** (top right)
2. Review the page
3. Click **Publish** to confirm
4. **Done!** 🎉

## Troubleshooting

### Embed appears blank
**Solution:** Make sure you copied the ENTIRE file (including `<!DOCTYPE html>` at the top)

### Layout looks broken
**Solution:** 
1. Set page width to "Full width" in settings
2. Make sure you selected "Full page" (not "Web page")

### Copy buttons ask for permission
**Solution:** This is normal - click "Allow" to enable clipboard access
