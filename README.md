# Behavior Layer Playbook

A framework for designing agentic system behavior across intent, context, quality, and coordination.

## Versions

- **POV Version** (`index-pov.html`) - Conceptual framework focused on design principles
- **Full Version** (`index.html`) - Complete version with additional features

## Viewing

Open either HTML file directly in your browser, or visit the GitHub Pages site:
https://ygando_sfemu.github.io/behavior-layer-playbook/

## Local Development

No build process required - just open the HTML files in your browser.

Each version has its own CSS and JS files:
- POV: `index-pov.html`, `script-pov.js`, `styles-pov.css`
- Full: `index.html`, `script.js`, `styles.css`

## About

This playbook helps teams align on agent behavior as a product quality concern across:
- Product Management
- Engineering
- UX & Conversation Design
- Content & Editorial
- Executive Leadership
