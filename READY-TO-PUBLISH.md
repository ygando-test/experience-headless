## 🆘 If Something Breaks

### Common Issues & Solutions

**Embed appears blank:**
- Make sure you copied the entire file
- Check that you selected "Full page" (not "Web page")
- Try a different browser

**Layout looks wrong:**
- Set page width to "Full width"
- Turn off "Show page title"
- Choose a minimal Google Sites theme

**Copy buttons don't work:**
- Click "Allow" when prompted
- This is browser security - totally normal

**Search doesn't work:**
- Wait 2-3 seconds after page loads
- Try typing slower

**Mobile layout broken:**
- This is rare - verify it's set to "Full page"
- Test in different mobile browsers

Full troubleshooting: See `EMBED-SETUP.md`
